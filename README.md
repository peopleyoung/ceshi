# ceshi · 网页版贪吃蛇

零构建、零第三方运行依赖的单页贪吃蛇（原生 HTML/CSS/JS + Canvas），实现在此仓库。
需求与验收口径见工作项 10046 的 PRD v1.1（AC-01~21）。

## 运行

方式一（直接双击打开，无需任何服务）：

```
用浏览器打开 index.html（file:// 即可，页面刻意不使用 ES module 以免被 CORS 拦截）
```

方式二（本地静态服务）：

```
python3 -m http.server 8000
浏览器访问 http://127.0.0.1:8000/
```

断网状态下两种方式均可完整游玩（无任何外部资源请求）。

## 操作

| 操作 | 键盘 | 触屏 | 按钮 |
|---|---|---|---|
| 开始 | 任意方向键 | 任意方向滑动 | 开始游戏 |
| 转向 | ↑↓←→ 或 W/A/S/D | 四方向滑动 | — |
| 暂停/继续 | 空格 或 P | — | 暂停/继续 |
| 重新开始 | Enter 或 R | — | 重新开始 |

规则：20×15 棋盘，初始蛇长 3 格朝右，150ms/格；吃到食物蛇长 +1、得分 +10；每 50 分提速 10ms（下限 80ms）；禁止 180° 直接反向；撞墙或撞到自己即结束，蛇填满棋盘判胜利；最高分记录在 `localStorage` 的 `snake.bestScore`。

## 代码结构

```
index.html          页面骨架、信息栏、覆盖层与样式
src/game.js         核心规则，不依赖 DOM（浏览器与 Node 共用，唯一规则真值）
src/render.js       Canvas 绘制薄壳，只读 state、无业务判断
src/main.js         事件绑定、节拍循环（requestAnimationFrame）、HUD、最高分持久化
tests/game.test.js  Node 原生断言，机械化回归规则类验收标准
```

## 自测

```
node tests/game.test.js
```

无需安装任何依赖。测试直接读写 `src/game.js` 导出的规则接口，覆盖转向队列、180° 反向、吃食物后长度与分数不变式、四向撞墙、撞身与蛇尾豁免、满盘胜利、重开保留最高分、速度曲线、暂停语义。

复测满盘胜利也可在浏览器地址栏用小棋盘打开同一页面：`index.html?cols=5&rows=5`（仅改变棋盘尺寸，其余规则不变；不带参数即默认 20×15）。
